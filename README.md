# myInvoices v0.10.0

Ελληνική τοπική εφαρμογή Windows για άντληση παραστατικών myDATA και αποθήκευση PDF ανά πελάτη και προμηθευτή. Νέα ανεξάρτητη υλοποίηση, όχι ανακτημένος πηγαίος κώδικας της παλιάς εφαρμογής.

## Εγκατάσταση

Απαιτείται Python 3.11+ με Tkinter. Αυτή η έκδοση παραδίδεται ως κώδικας, όχι αυτοτελές EXE.

1. Αποσυμπίεσε το ZIP σε νέο φάκελο.
2. Τρέξε **INSTALL_BROWSER.bat** μία φορά για τις δωρεάν βιβλιοθήκες λήψης και προβολής PDF. Χρειάζεται Internet για την εγκατάσταση. Χρησιμοποιείται εγκατεστημένο Edge ή Chrome στα Windows.
3. Άνοιξε **START_MYINVOICES.bat**.
4. Από **Πελάτης → Νέος πελάτης** όρισε όνομα, ΑΦΜ και API credentials του πελάτη. Δεν είναι κωδικοί TAXISnet.

Σε αναβάθμιση, κλείσε την προηγούμενη εφαρμογή και εγκατέστησε τη νέα σε νέο φάκελο. Οι ήδη καταχωρισμένοι πελάτες και τα credentials παραμένουν στην ίδια τοπική βάση· δεν χρειάζεται νέα καταχώριση.

Με `INSTALL.bat` λειτουργούν οι άμεσες λήψεις και η προβολή PDF χωρίς Playwright. Δυναμικές σελίδες που χρειάζονται JavaScript θα παραμένουν εκκρεμείς αν δεν έχει εγκατασταθεί η υποστήριξη browser. Το **Άνοιγμα στον browser** χρησιμοποιεί τον κανονικό προεπιλεγμένο browser των Windows και δεν απαιτεί Playwright.

## Τρία βασικά κουμπιά

### 1. Εύρεση παραστατικών

Επίλεξε πελάτη και περίοδο, και πάτησε **Εύρεση παραστατικών**. Γίνεται RequestDocs της ΑΑΔΕ και εμφανίζεται η λίστα, χωρίς αυτόματη λήψη PDF.

Η προεπιλογή είναι **ολόκληρος ο προηγούμενος ημερολογιακός μήνας** με βάση την ημερομηνία του υπολογιστή. Για παράδειγμα, στις 19/10/2026 είναι 01/09/2026–30/09/2026. Οι ημερομηνίες Από/Έως είναι συμπεριληπτικές και αφορούν την έκδοση παραστατικού. Enter εφαρμόζει τοπικά το φίλτρο· κάθε κύριο κουμπί διαβάζει ξανά τα πεδία.

Η πρόοδος ανά ακριβή περίοδο είναι ανεξάρτητη από τον γενικό συγχρονισμό. Παραστατικά, μεταβολές και συνέχεια κάθε σελίδας αποθηκεύονται μαζί, ώστε να υπάρχει συνέχιση χωρίς απώλεια ή διπλότυπα.

### 2. Λήψη PDF — χωρίς ορατά παράθυρα

Η εφαρμογή αποθηκεύει προεπιλεγμένα στην **Επιφάνεια εργασίας**, χωρίς να ζητά φάκελο κάθε φορά. Αναγνωρίζει και την Επιφάνεια εργασίας που έχει μεταφερθεί στο OneDrive μέσω του Windows Known Folder API. Από **Περισσότερα → Επιλογή φακέλου PDF** μπορείς να αλλάξεις τη βάση αποθήκευσης για τον επιλεγμένο πελάτη στην τρέχουσα συνεδρία.

Η εφαρμογή επιχειρεί:

- Απευθείας PDF ή μία ρητή πηγή από iframe/embed/object/JSON/base64/PDF.js.
- Για δυναμική ιστοσελίδα, φόρτωση JavaScript σε **headless browser**, χωρίς να ανοίγει ορατά το τιμολόγιο.
- Αν δεν βρεθεί αρχικό PDF αλλά έχει φορτωθεί αναγνωρίσιμο HTML παραστατικό, δεύτερη προσπάθεια με την ενσωματωμένη εκτύπωση Chromium. Το αντίγραφο αποθηκεύεται ως **PDF από εκτύπωση**.
- Αν βρεθεί ενεργό Cloudflare/CAPTCHA ή HTTP 403, καταγραφή ως εκκρεμότητα και συνέχεια στο επόμενο. Δεν ζητά να κάνεις κλικ στην πρώτη λήψη.

Προηγουμένως καταγεγραμμένα challenges της ίδιας διεύθυνσης παραλείπονται χωρίς νέο αίτημα. Ληφθέν αρχείο παραλείπεται μόνο αφού ελεγχθούν η ύπαρξη, το μέγεθος και το SHA-256 του. Άλλες εκκρεμότητες δεν παρουσιάζονται ως επιτυχής λήψη.

Η εκτύπωση επιχειρείται μόνο αφού προηγηθεί αναζήτηση του αρχικού PDF. Ελέγχεται ότι η φορτωμένη σελίδα και το παραγόμενο PDF περιλαμβάνουν στοιχεία του συγκεκριμένου παραστατικού. CAPTCHA, σελίδες εισόδου/σφάλματος, κενό αποτέλεσμα και εξωτερικά περιβλήματα PDF viewers δεν αποθηκεύονται ως παραστατικά. Για τους τελευταίους μπορείς να ανοίξεις τον σύνδεσμο στον browser και να εισάγεις PDF χειροκίνητα. Η αναμονή εκτύπωσης έχει όριο 20 δευτερολέπτων επιπλέον της φόρτωσης του browser.

Η αρχειοθέτηση γίνεται ανά πελάτη, μήνα έκδοσης και προμηθευτή:

```text
Επιφάνεια εργασίας/
  ΑΦΜ πελάτη/
    2026-10/
      ΑΦΜ προμηθευτή/
        MARK.pdf
    2026-09/
      ΑΦΜ προμηθευτή/
        MARK.pdf
```

Ο μήνας προκύπτει από την ημερομηνία έκδοσης του παραστατικού, όχι από την ημέρα λήψης. Το `έτος-μήνας` κρατά χωριστά τους ίδιους μήνες διαφορετικών ετών χωρίς επιπλέον φάκελο έτους. Σε σύγκρουση ονόματος προστίθεται μοναδική κατάληξη χωρίς αντικατάσταση. Οι δοκιμαστικοί πελάτες έχουν κατάληξη `_ΔΟΚΙΜΑΣΤΙΚΟ`. Τα προϋπάρχοντα αρχεία παραμένουν στη θέση τους και ανοίγουν από την καταγεγραμμένη θέση τους· δεν μετακινούνται ή διαγράφονται αυτόματα. Η νέα δομή εφαρμόζεται στις νέες αποθηκεύσεις και χειροκίνητες εισαγωγές.

### 3. Άνοιγμα στον browser — μόνο η επιλεγμένη εγγραφή

Επίλεξε ένα παραστατικό σε οποιαδήποτε από τις τρεις καρτέλες και πάτησε το κουμπί. Ανοίγει **μία φορά ο ακριβής σύνδεσμος `downloadingInvoiceUrl` που επέστρεψε η ΑΑΔΕ**, στον κανονικό προεπιλεγμένο browser σου. Λειτουργεί ανεξάρτητα από πάροχο ή προηγούμενη επιτυχία/αποτυχία. Αν δεν υπάρχει σύνδεσμος, εμφανίζεται σχετικό μήνυμα.

Η εφαρμογή δεν τροποποιεί το URL, δεν κάνει προηγούμενο αίτημα στον πάροχο, δεν παρακολουθεί τις Λήψεις και δεν επαναλαμβάνει το άνοιγμα. Η ενέργεια τελειώνει μόλις παραδοθεί ο σύνδεσμος στον browser. Το παλιό ανθρώπινο batch με αναμονή νέου PDF δεν καλείται πλέον από το γραφικό περιβάλλον. Η αυτόματη λήψη και η αυτόματη εκτύπωση παραμένουν στο **2. Λήψη PDF**.

Τυχόν CAPTCHA ολοκληρώνεται από εσένα στη σελίδα. Αν αποθηκεύσεις χειροκίνητα PDF και θέλεις να το συνδέσεις με την εγγραφή, χρησιμοποίησε **Περισσότερα → Χειροκίνητη εισαγωγή PDF**, με το σωστό παραστατικό επιλεγμένο.

## Άνοιγμα PDF και φακέλου

- **Άνοιγμα PDF:** επίλεξε αποθηκευμένο παραστατικό και πάτησε το κουμπί κάτω από τη λίστα, ή κάνε διπλό κλικ στην εγγραφή. Ανοίγει μέσα στην εφαρμογή σε ξεχωριστό παράθυρο με προηγούμενη/επόμενη σελίδα, μεγέθυνση/σμίκρυνση και κύλιση. Προβάλλεται μόνο το τοπικό αποθηκευμένο αρχείο, χωρίς browser, δίκτυο ή αλλαγή του πρωτοτύπου.
- **Φάκελος τιμολογίων:** ανοίγει στον Explorer τον φάκελο ΑΦΜ του επιλεγμένου πελάτη. Αν δεν υπάρχει ακόμη, δημιουργείται. Ακολουθεί τον τρέχοντα προορισμό, προεπιλεγμένα την Επιφάνεια εργασίας.

Η προβολή χρησιμοποιεί το δωρεάν `pypdfium2==5.13.0` και το PDFium, χωρίς πρόσθετο PDF reader ή Pillow. Οι άδειες των εξαρτήσεων εγκαθίστανται μαζί με το πακέτο. Η απόδοση κάθε σελίδας γίνεται στο παρασκήνιο με όριο ανάλυσης ώστε να μην φορτώνονται ταυτόχρονα όλες οι σελίδες. Αν το αρχείο λείπει ή έχει αλλάξει, εμφανίζεται αντιγράψιμο μήνυμα αντί για άσχετο ή ανύπαρκτο PDF.

## Διάταξη και επιπλέον ενέργειες

Περίοδος αριστερά, πραγματικά πλήθη σε κάρτες **Παραστατικά / PDF αποθηκευμένα / Εκκρεμή browser**, τρία βασικά βήματα δεξιά, λίστα από κάτω. Οι κάρτες αφορούν τον επιλεγμένο πελάτη και περίοδο. Η λίστα πελατών παραμένει ξεχωριστή με αναζήτηση.

- **Παραστατικά:** όλα τα παραστατικά της περιόδου, μαζί με όσα δεν έχουν δοκιμαστεί ή δεν έχουν σύνδεσμο PDF.
- **Επιτυχημένα:** αποθηκευμένα αρχικά PDF, εισαγωγές και αντίγραφα εκτύπωσης, με διαφορετική ένδειξη κατάστασης για κάθε τρόπο αποθήκευσης.
- **Αποτυχημένα:** δοκιμασμένες λήψεις χωρίς αποθηκευμένο αποτέλεσμα, με την αιτία αποτυχίας. Οι εκκρεμότητες CAPTCHA παραμένουν εδώ μέχρι να αποθηκευτεί PDF με λήψη ή χειροκίνητη εισαγωγή. Το άνοιγμα συνδέσμου μόνο του δεν αλλάζει κατάσταση. Ακυρωμένα παραστατικά παραμένουν στα «Παραστατικά»· αν είχαν αποθηκευτεί, φαίνονται και στα «Επιτυχημένα» με ένδειξη ακύρωσης.

Κάθε καρτέλα έχει δική της σελιδοποίηση έως 200 εγγραφών ανά σελίδα. Η ταξινόμηση αφορά τον τρέχοντα σύνδεσμο του παραστατικού και διατηρείται μετά την επανεκκίνηση. Όσα δεν έχουν δοκιμαστεί δεν μετρώνται ως αποτυχίες. Αν σε επόμενη λήψη εντοπιστεί ότι αποθηκευμένο αρχείο λείπει ή έχει αλλάξει, επανεπιχειρείται λήψη και ενημερώνεται η κατάστασή του. Το αλλαγμένο αρχείο δεν διαγράφεται.

- **Πελάτης:** νέα εγγραφή, επεξεργασία, τοπική ανανέωση. Διπλό κλικ στον πελάτη ανοίγει τα στοιχεία του.
- **Περισσότερα:** έλεγχος API, άνοιγμα ενός επιλεγμένου, χειροκίνητη εισαγωγή, αλλαγή προορισμού, προηγούμενος μήνας ή όλες οι ημερομηνίες.
- **Μηνύματα:** αντιγραφή τελευταίου σφάλματος/όλων και καθαρισμός. Το πλαίσιο υποστηρίζει Ctrl+A/C.
- **Διακοπή εργασίας:** εμφανίζεται μόνο όταν τρέχει εργασία.

## Credentials και δεδομένα

Κλειδιά ανά πελάτη. Με κλειδιά του ίδιου του πελάτη δεν ενεργοποιείς εκπροσώπηση· το `entityVatNumber` αποστέλλεται μόνο με ρητή επιλογή χρήσης εξουσιοδοτημένου εκπροσώπου. Δεν καλείται ξεχωριστό endpoint ελέγχου εξουσιοδότησης.

Στα Windows τα credentials προστατεύονται με DPAPI του τρέχοντος χρήστη, δεσμευμένα στο client ID/ΑΦΜ/περιβάλλον. Δεν μεταφέρονται σε άλλο Windows χρήστη. Σε Linux αποθηκεύονται μόνο στη μνήμη. Δεν αποστέλλονται στους παρόχους PDF.

Βάση και credentials: `%LOCALAPPDATA%\myInvoicesStarter` στα Windows. Η SQLite περιέχει λογιστικά δεδομένα/XML/links και δεν είναι κρυπτογραφημένη — μην την κοινοποιείς. Το schema παραμένει 4· διατηρούνται δεδομένα/πρόοδος προηγούμενων εκδόσεων. Αναβαθμίσεις παλαιότερων schemas δημιουργούν αυτόματο ελεγμένο backup.

Η κατάσταση «PDF αποθηκευμένο» σημαίνει πραγματική αποθήκευση με έλεγχο δομής, όχι ανεξάρτητη λογιστική επαλήθευση του περιεχομένου. Το «PDF από εκτύπωση» είναι αντίγραφο της προβολής, με διαφορετικά bytes από το αρχικό PDF του παρόχου· δεν διατηρεί τις ψηφιακές υπογραφές του πρωτοτύπου. Εσωτερικά παραμένουν διακριτές οι καταστάσεις πηγής, λήψης και ανεξάρτητης επαλήθευσης. Όριο τελικού PDF 40 MB/500 σελίδες, χωρίς αντικατάσταση αρχείων. Ο browser μπορεί να μεταφέρει δεδομένα πριν ελεγχθεί το τελικό μέγεθος.

Δεν υλοποιείται ακόμη OCR. Η [έρευνα εργαλείων και παρόμοιων προβλημάτων](docs/PDF_RECOVERY_RESEARCH.md) εξηγεί γιατί πρώτα ανακτούμε το έγγραφο και μετά προσθέτουμε αναγνώριση για αρχειοθέτηση. Η εκτύπωση χρησιμοποιεί τον υπάρχοντα Chromium· δεν χρειάζεται νέος printer, συνδρομή ή υπηρεσία cloud.

## Ανάπτυξη και έλεγχοι

```text
python -m pip install -r requirements-browser.txt
PYTHONPATH=src python -m unittest discover -s tests -v
PYTHONPATH=src python -m myinvoices --check-demo
python -m compileall -q src tests
```

Στο PowerShell ορίζεις `$env:PYTHONPATH = "src"`. Τα GUI tests χρειάζονται οθόνη ή Xvfb. Τα προαιρετικά browser tests χρησιμοποιούν πραγματικό system Chromium και συνθετικές αποκρίσεις, όχι πραγματικά παραστατικά. Το native DPAPI test εκτελείται μόνο σε Windows.

Το `demo_only.bat` / `--demo` λειτουργεί χωρίς δίκτυο και έχει χωριστή βάση με συνθετικά στοιχεία. Το `CHECK_AADE.bat` κάνει μόνο έλεγχο σύνδεσης με τα αποθηκευμένα τοπικά credentials, χωρίς πρόοδο/αποθήκευση παραστατικών. Το `run_demo.bat` είναι παλιό όνομα για την κανονική εκκίνηση· για demo χρησιμοποίησε ρητά το `demo_only.bat`.

Πηγές API και περιορισμοί live ελέγχου: [AADE_RESEARCH.md](docs/AADE_RESEARCH.md). Ιστορικό υλοποίησης/δοκιμών: [ASSESSMENT.md](docs/ASSESSMENT.md). Native Windows και πραγματική επιτυχία CAPTCHA/λήψης στους συγκεκριμένους παρόχους δεν έχουν επαληθευτεί από το cloud περιβάλλον.
